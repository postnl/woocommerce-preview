Woocommerce PostNL plugin

Met deze handleiding stel je stap voor stap de PostNL plugin voor WooCommerce in. Je hoeft hiervoor geen technische kennis te hebben. Begin bij de installatie en volg daarna de configuratiestappen.

Snel starten?
Wil je de plugin zo snel mogelijk gebruiken? Volg dan deze stappen:
  1. Installeer de plugin via WordPress.
  2. Vul je PostNL klantnummer, klantcode en API key in.
  3. Koppel je WooCommerce verzendmethode aan PostNL.
  4. Maak een testorder aan en controleer of je een label kunt aanmaken.

1 Waarvoor gebruik je deze plug-in?

Deze handleiding beschrijft de functionaliteiten en de installatie van de PostNL plugin voor WooCommerce.

Met deze plugin kun je onder andere:

  • Eenvoudig zendingen voormelden bij PostNL en verzendlabels printen.
  • Bezorgopties in de check-out aanbieden (Ophalen bij een PostNL punt, Dagkeuze en Avondbezorging).
  • Retourlabels creëren.
  • Valideren van Nederlandse adressen.
  • Aanbod van verschillende verzendproducten.

De plug-in kan zowel door Nederlandse als Belgische webwinkeliers gebruikt worden.

2 Installatie

Wij adviseren om de installatie van de plugin altijd eerst op een testomgeving uit te voeren en om altijd een back-up van je webshop te maken voordat je begint.

De installatie duurt meestal maar een paar minuten en kan je op twee manieren uitvoeren:

  1. Aanrader:Via de WordPress plugin directory (meest eenvoudig)
  2. De plugin handmatig uploaden

2.1 Via de WordPress plugin directory (aanrader)

Om de PostNL plugin te installeren via de WordPress plugin directory volg je onderstaande stappen:

  1. Ga in WordPress naar het menu Plugins → Nieuwe plugin.
  2. Typ in de zoekbalk het woord PostNL en klik op zoeken.
  3. Kies de plugin PostNL for WooCommerce en klik op Nu installeren. De plugin wordt gedownload.
  4. Wanneer het downloaden voltooid is, klik je op Plugin activeren.

2.2 Handmatig uploaden (geavanceerd)

Wilt u de PostNL plugin handmatig uploaden en installeren? Volg dan onderstaande stappen:

  1. Download de zip file van de plugin via deze site
  2. Klik rechtsboven op de groene knop Code → Download ZIP
  3. Ga in WordPress naar het menu Plugins → Nieuwe plugin.
  4. Klik bovenin het scherm op Uploaden.
  5. Kies het bestand en klik op Nu Installeren.
  6. Wanneer de download klaar is klikt je op Plugin activeren.

3 Configuratie

Ga naar het menu WooCommerce → Instellingen → Verzendmethoden → PostNL om de PostNL plugin te configureren.

3.1 Account instellingen

In dit onderdeel koppel je jouw webshop aan PostNL. Zonder deze instellingen werkt de plugin niet.

Belangrijk:
Vul eerst alle gegevens in via de Sandbox (testomgeving). Controleer daarna of alles werkt en schakel pas daarna over naar de productieomgeving.

3.1.1 Modus omgeving

Je kunt kiezen tussen Sandbox en Productie.

  • Sandbox (aanrader om mee te beginnen)
    Dit is een testomgeving. Hier kun je zendingen aanmaken om je instellingen te controleren.
  • Productie
    Dit is de live omgeving. Alleen zendingen in deze omgeving kun je daadwerkelijk inleveren bij PostNL.
Let op:
Het aanmaken van een label of zending is kosteloos. Een zending wordt pas in rekening gebracht zodra deze voor het eerst wordt gescand door PostNL.
Let op:
Ga je live met je webshop? Zorg dan dat je de omgeving hebt ingesteld op Productie. Zendingen die via de Sandbox-omgeving worden aangemaakt, worden niet voorgemeld bij PostNL en kunnen daardoor met een toeslag verwerkt worden.

3.1.2 API key

Voor zowel de Sandbox als de Productieomgeving heb je een aparte API key nodig.

Je vindt deze in je Mijn PostNL-omgeving:

  1. Klik rechtsboven op je gebruikersnaam
  2. Klik op Mijn Account
  3. Ga naar API beheren

Hier vind je twee API keys:

  • Sandbox API key (voor testen)
  • Productie API key (voor live gebruik)

Stel de plugin als volgt in:

  1. Selecteer Sandbox als omgeving
  2. Vul de Sandbox API key in
  3. Klik op Opslaan
  4. Schakel daarna over naar Productie
  5. Vul de Productie API key in
  6. Klik opnieuw op Opslaan

3.1.3 Logging

Activeer logging wanneer je problemen hebt met de plugin.

Hiermee kun je technische fouten terugvinden en sneller oplossen.

3.1.4 Klantgegevens

Vul hier je PostNL-klantnummer (bijv. 123456) en klantcode (bijv. ABCD) in.

Deze gegevens vind je in je Mijn PostNL-omgeving.

Let op:
Heb je meerdere klantcodes? Kies er dan één. Je kunt er slechts één tegelijk gebruiken in WooCommerce.

3.2 Retour Instellingen

In dit onderdeel stel je in hoe retourzendingen via PostNL worden afgehandeld.

3.2.1 Standaard retouroptie

Kies hoe je retourlabels wil aanbieden aan je klanten.

3.2.2 Smart Return activeren

Wanneer deze instelling aangevinkt staat, is het mogelijk om vanuit het Label & Tracking menu in WooCommerce een Smart Return barcode op te sturen naar de consument per e-mail.

De consument kan vervolgens bij een PostNL-punt deze barcode laten scannen om de retourzending te versturen

3.2.3 Retour naar huisadres

Schakel deze instelling in als je retourzendingen wilt ontvangen op een huisadres.

Als deze instelling uit staat, worden retouren naar het opgegeven antwoordnummer gestuurd.

Een antwoordnummer kan worden aangevraagd via de PostNL Sales afdeling. Zij zijn te bereiken via de volgende contactgegevens 088-868 6868 ; business@postnl.

3.2.4 Klantcode retouren

De klantcode Retouren is niet hetzelfde als de klantcode die je bij Account Instellingen hebt ingevuld.

Je klantcode Retouren vind je in je Mijn PostNL-omgeving.

Let op:
Het is niet mogelijk om meerdere klantcodes retouren te koppelen in WooCommerce.

3.3 Checkout Instellingen

In dit onderdeel stel je de bezorgopties in die aan klanten worden getoond tijdens het afrekenen.

Voor een basisconfiguratie zijn meestal alleen de volgende instellingen nodig:

  • Verzendmethode(n)
  • Bezorgdagen
  • Overkomstduur
  • Cut off tijd
  • Verzenddagen

3.3.1 Verzendmethode(n)

De PostNL plug-in kan gebruikt worden met alle verzendmethoden die in WooCommerce beschikbaar zijn. Geef hier aan voor welke verzendmethode(n) je gebruik wil maken van de diensten van PostNL. Selecteer je hier bijvoorbeeld 'Vast tarief', dan kunnen de orders die met de verzendmethode 'Vast tarief' zijn binnen gekomen direct worden voorgemeld bij PostNL.

Verzendmethode 'PostNL' hoeft niet gekoppeld te worden aan de checkout in het kader Shipping Methods, deze verzendmethode is direct te gebruiken. Verzendmethoden die niet verzendmethode 'PostNL' zijn, moeten wel altijd gekoppeld worden aan de checkout.

3.3.2 Ophalen bij een PostNL-punt

Door de functionaliteit Ophalen bij een PostNL-punt te activeren kunnen jouw Nederlandse en Belgische klanten in de checkout kiezen om hun bestelling op te halen bij een PostNL-punt i.p.v. de bestelling thuis te ontvangen. Met deze optie vergroot je de controle van jouw klanten over hun bestelling.

Steeds meer klanten kiezen ervoor om hun pakket op te halen wanneer het hen uitkomt. Door in te stellen dat de PostNL-punten als eerste worden getoond in de checkout, speel je daar slim op in.  Dit doe je door het in het veld "Default Delivery Options Tab” de optie 'Pickup Points” te selecteren.

3.3.3 Bezorgdagen

Door Bezorgdagen te activeren kunnen jouw Nederlandse en Belgische klanten in de checkout bepalen op welke dag zij hun pakket thuis ontvangen. Wist je dat het aanbieden van bezorgopties conversie-verhogend kan werken? Probeer het nu zelf.

Jij bepaalt hoeveel bezorgdagen er in de checkout zichtbaar zijn. Het dagen kan variëren tussen 1 en 6 dagen.

Let op, hou bij het overhandigen van de pakketten aan PostNL rekening met de gekozen bezorgdag. Kiest de consument om volgende week donderdag de bestelling te ontvangen, dan dien jij op woensdag het pakket aan PostNL te overhandigen (uitgaande van een overkomstduur van 1 dag).

3.3.4 Ochtend bezorging

Voor klanten die hun pakket alleen overdag in ontvangst kunnen nemen kan je gebruik maken van ochtend bezorging.

Door Ochtend bezorging te activeren geef je jouw klanten deze mogelijkheid. Deze functie is alleen beschikbaar voor Nederlandse ontvangers

3.3.5 Avondbezorging

Consumenten die overdag niet huis zijn geven de voorkeur om ’s avonds hun bestelling te ontvangen.

Door Avondbezorging te activeren geef je jouw klanten deze mogelijkheid. De kosten voor een avondzending liggen hoger. Jij kunt een deel van deze hogere kosten doorberekenen aan jouw klanten door een toeslag voor avondbezorging te vragen. Deze functie is alleen beschikbaar voor Nederlandse ontvangers

3.3.6 Overkomstduur

Met de overkomstduur geef je aan hoeveel dagen je nodig hebt om de bestelling gereed te maken.

Stel dat er vandaag een bestelling wordt geplaatst die je morgen al kan bezorgen, dan is de overkomstduur 1.

3.3.7 Cut-off tijd

De cut off tijd geeft aan tot welk tijdstip een bestelling geplaatst kan worden zodat de overkomstduur gehaald kan worden.

Voor bestellingen die na de cut off tijd besteld worden, wordt er één dag bij de overkomstduur opgeteld.

3.3.8 Verzenddagen

Geef aan op welke dagen je de pakketten aan PostNL overhandigt. Deze gegevens zijn nodig om het eerst volgende bezorgmoment te kunnen bepalen.

Overhandig jij ook op zondag pakketten aan PostNL? Zorg dan dat het contractueel is vastgelegd dat PostNL jouw pakketten op zondag sorteert. Alleen dan kunnen jouw klanten op maandag hun bestelling ontvangen.

3.3.9 Valideer Nederlandse adressen & Gebruik PostNL Adresvelden

Om te voorkomen dat foutieve adressen worden ingevoerd, kan de adrescheck geactiveerd worden. Deze adrescheck valideert Nederlandse adressen. Als het adres niet bekend is wordt de consument gewaarschuwd zodat hij/zij het adres kan aanpassen.

Belangrijk: voor het correct functioneren van bepaalde functies van de plug-in zoals adresvalidatie en Invullen Met PostNL, is het noodzakelijk dat de adresvelden gescheiden worden in een straatnaamveld en velden voor huisnummer en huisnummertoevoeging. Wanneer deze velden met elkaar gecombineerd worden kan het voorkomen dat bepaalde functies niet goed meer werken en er onjuiste adresgegevens op de labels komen. We raden dan ook af om middels thema's of customisation-plug-ins dergelijke aanpassingen te maken aan de check-out velden.

Het is daarom aan te raden om de PostNL adresvelden te activeren. In de checkout worden dan aparte velden getoond voor de straatnaam, huisnummer en huisnummertoevoeging.

3.3.10 Automatische toewijzing van brievenbuspakjes

(Let op: deze functie is alleen beschikbaar voor bestellingen binnen Nederland)

De plug-in beschikt over een functie waarmee automatisch het product Brievenbuspakje gekoppeld wordt aan zendingen die door een brievenbus passen. Deze functie past ook de check-out daarop aan zodat klanten weten dat ze niet thuis hoeven te blijven voor hun bestelling. Om gebruik te maken van deze functie moet deze per product worden ingeschakeld, en tevens moet aangegeven worden hoe vaak dit product in een enkel brievenbuspakje past (inclusief eventueel verpakkingsmateriaal). Ga hiervoor naar Producten → Open een product → Productgegevens – Verzending. In het daaropvolgende scherm vink je de optie “Activeer automatische toewijzing Brievenbuspakje” aan en vul je in het kader daaronder in hoe vaak dit product in een brievenbuspakje past. 3.3.11 Toeslagen

Het is mogelijk om voor bepaalde verzendproducten een toeslag of alternatieve verzendkosten in rekening te brengen, die automatisch bij de getoonde verzendkosten worden opgeteld. Hiermee kun je de extra kosten die bij sommige verzendproducten komen kijken doorberekenen naar de ontvanger. Daarnaast kun je het gebruiken om de keuze voor sommige verzendproducten aan te moedigen:

  • Afhaalpunten
    Gebruik deze instelling wanneer je een toeslag in rekening wil brengen voor zendingen die naar een PostNL-punt verstuurd worden
  • Thuisbezorging
    Gebruik deze instelling wanneer je een toeslag in rekening wil brengen voor zendingen die bij de klant thuisbezorgd worden.
  • Alternatieve verzendkosten brievenbuspakje
    Gebruik deze instelling om een alternatieve prijs te hanteren voor bestellingen die volgens de Automatische Brievenbuspakjes-berekening in een brievenbuspakje passen. Deze alternatieve prijs vervangt de standaard verzendkosten.
  • Toeslag voor het brievenbuspakje (24 uur)
    Gebruik deze instelling wanneer je de hogere kosten voor het product Brievenbuspakje (24 uur) wil doorberekenen naar de ontvanger.
  • Ochtendbezorging & Avondbezorging
    Gebruik deze instellingen wanneer je een toeslag wil doorberekenen voor verzendingen die in de ochtend of juist in de avond geleverd moeten worden. Deze toeslag wordt aangegeven in het Bezorgdagen-tabblad in het bezorgoptiemenu.

3.4 Versturen buiten Europa

3.4.1 Pakketten non EU Barcode Type en Pakketten non-EU Klantcode

Voor het versturen van pakketten buiten Europa (Pakketten non-EU) zijn extra klantgegevens nodig. Deze gegevens zijn nodig om de juiste barcode te genereren. Vul jouw Pakketten non-EU Type en Pakketten non-EU Klantcode in. Deze gegevens zijn terug te vinden in jouw Zakelijke PostNL omgeving.

Bij Pakketten non-EU Type dienen enkel de twee letters van de Pakketten non-EU Klantcode ingevuld te worden en bij Pakketten non-EU Klantcode enkel de vier cijfers. Ook hier geldt dat er slechts één Pakketten non-EU klantcode gebruikt kan worden.

3.4.2 GS tarief code en land van herkomst

De GS tarief code en land van herkomst is benodigde informatie voor de douaneformulieren. Deze gegevens dienen voor elk product dat in jouw webshop wordt aangeboden beschikbaar te zijn.

Ga naar Producten → Open een product → Productgegevens – Verzendmethoden en voer het land van herkomst en de GS tarief code in. Herhaal dit voor elk product.

Is de GS tarief code en het land van herkomst voor bijna alle producten hetzelfde? Vul dan bij de algemene PostNL instellingen een Standaard GS tarief code en een Standaard land van herkomst in. Deze gegevens worden overgenomen voor de douaneformulieren als er op productniveau geen GS tarief code of land van herkomst bekend is.

3.5 Printer en Email Instellingen

3.5.1 Printer Type

Geef met deze instelling op in welk bestandstype de labels afgedrukt moeten worden. Voor een optimale printkwaliteit en een zo laag mogelijk risico op problemen met de leesbaarheid van labels kies je bij voorkeur het native bestandstype van de printer waar de labels mee geprint gaan worden

3.5.2 Labelformaat

Welke type printer gebruik je om labels te printen? Gebruik je een labelprinter selecteer dan A6 labelformaat. Selecteer labelformaat A4 als je gebruik maak van een reguliere printer.

3.5.3 WooCommerce Email en Tekst

Wil je jouw klanten vanuit WooCommerce een Track & Trace mail sturen? Zet het vinkje achter WooCommerce Email dan aan. In het WooCommerce Email Tekst veld kan je aangeven welke tekst er in deze mail word meegestuurd. Onze tekstsuggestie is "Gebruik deze link om jouw zending te volgen: {tracking-link}"

Wil je meer controle over de notificaties? Bekijk dan de mogelijkheden in de Notficatie sectie in MijnPostNL Zakelijk.

3.6 Standaard verzendopties instellen

Kijk voor meer informatie over de internationale verzendproducten op de informatiepagina of neem contact op met uw PostNL accountmanager.

Brievenbuspakje 48 uur
Keuze aan ontvanger

Wanneer de keuze aan de ontvanger wordt gelaten worden beide opties in de check-out getoond met de bijbehorende prijzen (zie voor uitleg over de toeslagen paragraaf 3.3.11)

4 Verzendklassen en verzendprijs

Met de installatie van de PostNL plug-in is ook een PostNL Verzendmethode aangemaakt. Deze verzendmethode koppel je aan de WooCommerce Verzendzones. Maak je liever gebruik van de standaard WooCommerce verzendmethoden? Geen probleem! Ook deze kan je koppelen aan de PostNL functionaliteiten, zie '3.3. Verzendmethode(n)'. Per verzendzones kan je de verzendprijs bepalen.

Wanneer je geen gebruik wil maken van gratis verzenden boven een bepaald bedrag dient dit veld leeggelaten te worden.

Met de PostNL verzendmethode kan je ook Gratis Verzenden aanbieden vanaf een bepaald orderbedrag. Geef aan wat het minimale totale orderbedrag is voor Gratis Verzenden.

5 Orders verwerken

5.1 Orderoverzicht

In het orderoverzicht is te zien voor welke bestelling gekozen is voor verzending met PostNL. Deze bestellingen zijn te herkennen doordat via PostNL onder de bestemming staat. In de PostNL Tracking kolom is de barcode te zien van de zending van deze order. Dit is ook een link naar de consumenten Track & Trace pagina van PostNL.

Aan de rechterzijde vind je in de kolom Acties tevens een knop waarmee direct een label aangemaakt kan worden.

5.2 Orderpagina

Open een order. Rechts boven op de orderpagina is het PostNL menu te zien. Hierin is te zien om welke Type bezorging het gaat; standaard bezorging, ophalen bij een PostNL-punt, Avonbezorging, Europese bezorging of Wereldzending. Ook is de ‘Bezorgdatum’ van de bestelling te zien. Let op, houdt rekening met deze bezorgdatum om te bepalen wanneer de pakketten aan PostNL overhandigd moeten worden.

5.3 Extra verzendopties

Het is mogelijk om een extra verzendoptie toe te voegen aan de PostNL zending.

Afhankelijk van het type bezorging is het mogelijk om de zending:

  • te verzekeren (verzekerd bedrag is totale verzendbedrag)
  • retour te sturen als ontvanger niet thuis is
  • handtekening voor ontvangst te vragen
  • te controleren met de ID check
  • het pakket alleen bij de ontvanger te bezorgen (niet bij buren)
  • of het type bezorging te wijzigen naar Brievenbuspakje.

5.4 Aantal labels

In het PostNL menu is het mogelijk om het aantal labels van een zending te wijzigen. Zo kan het bijvoorbeeld voorkomen dat een zending opgedeeld moet worden naar twee pakketten omdat de zending anders te groot of te zwaar is. Verander het aantal labels in dit geval naar 2. Er kunnen maximaal 10 labels per order aangemaakt worden. Indien dit niet toereikend is raden we aan de order te dupliceren.

5.5 Creëer retourlabel

Bij de Retour Instellingen is aangegeven of er wel/niet altijd een retour-label geprint moet worden bij het aanmaken van het heenzending. Deze instelling wordt in dit menu overgenomen. Aan de hand van het ‘Creëer retourlabel’ vinkje is het mogelijk om de Retour Instellingen te overschrijven. Daarnaast is het mogelijk om via het Label & Tracking menu een Smart Return barcode op te sturen naar het e-mailadres wat aan die order gekoppeld staat. Gebruik hiervoor de knop "Zend Smart Return email".

5.6 Label verwijderen

Wil je na het aanmaken van een zending de opties wijzigen en een ander type zending aanmaken voor de betreffende order? Klik dan op Verwijder Label en maak opnieuw het label aan met de juiste verzendopties.

5.7 Zending aanmaken en verzendlabel printen

Staan alle vinkjes in het PostNL menu zoals gewenst? Klik dan onderaan in het menu op ‘Zending aanmaken’. Met deze actie wordt de zending voormeld bij PostNL. Klik vervolgens op ‘Print Label’ om het verzendlabel te downloaden.

5.8 PostNL Bulkacties

5.8.1 PostNL Label Aanmaken

Met deze actie kun je in één keer alle geselecteerde orders afdrukken, die vervolgens in één PDF bestand gedownload kunnen worden. Dit betekent dat de plug-in op basis van de geconfigureerde Standaard Verzendopties en de automatische brievenbusberekening (mits in gebruik) productcodes toewijst aan de geselecteerde orders. Op basis daarvan worden de labels gegenereerd. In dit menu kun je tevens aangeven uit hoeveel labels de orders moeten bestaan, wat de startpositie is voor printen op A4-papier en of er retour labels aangemaakt moeten worden.

Wanneer je op Uitvoeren klikt zal er bovenin een downloadlink verschijnen waarmee je alle aangemaakte labels kunt downloaden.

5.8.2 PostNL Verander verzendopties

Wil je voor één of meerdere zendingen afwijken van de geconfigureerde standaard verzendoptie of de automatische brievenbuspakje-toewijzing? Gebruik dan deze functie. Hiermee worden in één keer de geselecteerde orders aangepast met een andere verzendoptie. Let wel op dat er geen overlap zit in de binnenlandse en buitenlandse producten. Als de verzendopties van meerdere orders tegelijkertijd aangepast moeten worden, dan kan dit alleen als alle geselecteerde orders naar dezelfde levergebieden (Nederland, België, EU, non-EU) verstuurd zullen worden.
